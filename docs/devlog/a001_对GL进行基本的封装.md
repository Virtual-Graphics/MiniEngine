## 为什么是从 OpenGL 作为上层的第一个模块开始写
首先是因为 Hazel 就是这么干的，而我师从 Hazel 所以很大一部分原因是 Hazel 是从 Renderer 开始写的，当然 Hazel 从 Renderer 开始写也是因为渲染是游戏引擎中最为重要的模块之一，场景需要建立在 Renderer 之上，物理需要建立在 Renderer 之上等等，没有 Renderer 可以说就没有游戏引擎。因为我曾经对游戏引擎的定义就是：可交互可视化艺术创作工具。很重要的一点就是可视化，所以我们先写 Renderer，而需要让我们能够手写出一个拥有炫酷现代可视化效果的渲染器，则我们就不应该在开发各种上层的 graphics features 时还在处理底层非常繁琐的 graphic api，所以我们需要对 OpenGL 进行一层封装，即使 OpenGL 已经比 Vulkan 简单非常多，但为了更进一步减少心理负担，我们需要封装。
